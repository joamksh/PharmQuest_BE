# 분류 정책 v1-draft

서비스 탐색을 위한 분류 정책 초안이다. 의약품 사용·처방 지침이 아니다. 아래 우선순위는 제품 정책상의 제안이며 실제 데이터 검수에서 적합성을 확인한 뒤 확정한다.

## 근거 원칙

효능·적응증과 사용 목적을 우선한다. 성분명만으로 효능을 추정하지 않는다. 경고문·부작용·금기에 등장한 증상은 치료 대상의 근거가 아니다. 명시적인 부정 문장은 해당 효능의 근거가 아니다. 효능 정보가 없거나 서로 모순되면 검토 대기로 분리한다.

| 값 | 포함 기준 |
| --- | --- |
| PAIN_RELIEF | 원문이 통증 완화 또는 해열을 명시 |
| DIGESTIVE | 원문이 소화·위장관 증상 완화를 명시 |
| COLD | 원문이 감기 증상·기침·가래·감기에 따른 코막힘 완화를 명시 |
| ALLERGY | 원문이 알레르기 증상 완화를 명시 |
| ANTISEPTIC | 원문이 상처 부위 소독 또는 감염 예방을 위한 소독을 명시 |
| MOTION_SICKNESS | 원문이 이동/탑승에 따른 멀미 예방·완화를 명시. 일반적인 구역·구토 또는 Antiemetic이라는 단어만으로 판정하지 않음 |
| EYE_DROPS | 원문이 눈에 직접 투여하는 제품임을 명시 |
| OTHER | 충분한 효능 정보가 있으나 위 범주에 해당하지 않음 |

ALL은 정답이나 모델 출력으로 사용하지 않는다. OTHER와 정보 부족/오류를 구분한다.

## 복수 항목 우선순위 초안

1. 눈에 직접 투여하는 제품이면 기존 탐색 메뉴와의 호환성을 위해 EYE_DROPS를 우선한다.
2. 원문에 주된 사용 목적이 명시되면 해당 범주를 선택한다. 단순 문장 순서는 주된 목적의 근거가 아니다.
3. 감기 복합 증상 완화가 명시된 경우 포함된 통증·해열 성분만 보고 PAIN_RELIEF로 분류하지 않고 COLD로 분류한다.
4. 위 기준으로 대표 항목 하나를 정할 수 없으면 검토 대기. 임의의 enum 순서로 정답을 강제하지 않는다.

정책 변경 시 버전을 올리고 변경 영향이 있는 정답을 재검수한다. 과거 정책으로 평가한 점수와 새 정책 점수를 같은 조건의 모델 개선으로 주장하지 않는다.
